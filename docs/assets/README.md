# README visual assets

## Real LOL-v1 comparisons

`comparisons/lol_eval15_*.png` show **input → enhanced → GT** at native 600 × 400 resolution. Input and GT come from the real paired `eval15/low` and `eval15/high` images of the [LOL dataset introduced by Wei et al., BMVC 2018](https://daooshee.github.io/BMVC2018website/). The dataset images belong to their respective authors.

The four samples (`1.png`, `111.png`, `146.png`, `179.png`) are the first four PNG filenames in lexicographic order, matching the repository's evaluation order. They were selected independently of their scores. GT is never passed to the model.

Enhanced images are freshly generated by the repository model in evaluation mode, on CPU with float32 inference, from `outputs/color_safe_gpu_denoise/checkpoints/best_psnr.pt`. This checkpoint was saved at epoch 28 of the 60-epoch run. Its embedded model configuration matches `configs/comparison/ultralite_color_safe_gpu_denoise_60.yaml` (707 parameters, width 8, three separable blocks, shared coupled RGB curve, four iterations, no denoise head).

Panels contain the original pixels, without crops or spatial resizing. Enhanced pixels use the repository's standard clamp / round-to-8-bit conversion. No extra enhancement, denoising, sharpening, or color adjustment is applied. Each figure reports the repository's PSNR and SSIM on float32 enhanced output against GT, before 8-bit conversion; different runtimes can produce small numerical differences.

[provenance.json](comparisons/provenance.json) records the checkpoint SHA-256, source-file SHA-256 values, output pixel / figure hashes, model configuration, runtime, and per-image metrics.

To regenerate, install the normal project requirements, place the original LOL-v1 dataset and trained checkpoint at the documented paths, and run from the repository root:

```bash
python docs/generate_readme_comparisons.py
```

The script also accepts `--dataset`, `--checkpoint`, and `--output`. Arial or DejaVu Sans must be available for figure labels. Checkpoints and the full dataset remain excluded from Git; training a new checkpoint will produce different outputs.

## Architecture diagram

[architecture.svg](architecture.svg) is the editable vector source embedded in both READMEs and the architecture documentation. It follows `models/ultralite_dce.py`, `models/blocks.py`, and `models/curve.py` for the comparison configuration.

Parameter counts include convolution biases: stem **224**, three depthwise-separable blocks **3 × 152**, and curve head **27**, totaling **707**. Resize, RGB coupling, and iterative enhancement have no trainable parameters. The curve estimator processes the half-resolution grid, while the original input and all four enhancement steps retain full resolution.
